## 工单（每项一个 commit）

### T1 UI 通道全量
```python
class UI:
    async def confirm(self, message: str, *, danger: bool = False) -> bool
    async def select(self, title: str, options: list[Option]) -> Option | None
    async def input(self, message: str, *, default: str = "") -> str | None
```
- `Option(label, value, description="")`（dataclass）。
- **双路径**：turn 运行中 → 实时区内联对话框（对话框行经 painter 画在实时区顶部/追加区，键位经 raw 读取器收 y/n/esc 或上下+enter；实现可复用 04 号的键位源抽象）；空闲 → questionary（dialogs.py 既有，confirm 用 questionary.confirm 或 select 两项）。非交互 → confirm 返回 False、select/input 返回 None（§5.7 表：不可用）——docstring 与文档写明"调用方先查 `ui.is_interactive`"。
- `confirm` 的 danger 形态：红色边框/前缀。

### T2 header 接线
- `header.set(lines)`：下次提示符前打印这些行（进滚动缓冲，打印式——总纲裁决 #4）；`set([])` 清除；REPL 每轮 prompt 前检查脏标记。非 TTY 忽略。
- 内置消费者：无（这是纯贡献点；`ui.set_status` 瞬时覆盖已随 status bar 在 04 号）。

### T3 命令菜单
- 提交内容恰为 `/`（或 `/?`）时：不进 dispatch，弹出 registry 驱动的选择器（`ui.select` 或直接 questionary——空闲路径）：列出全部命令（name + description，含插件命令），选中即把该命令名填回输入（不自动执行）。
- 触发点在 `_dispatch` 之前（app 层）；`/help` 语义不变。
